# Learning Basic ABAP Programming

This repository documents my learning journey through the SAP Learning course **[Basic ABAP Programming](https://learning.sap.com/courses/basic-abap-programming)**.

It is structured as a public learning portfolio, with theory notes, code examples, and exercises for each unit of the course. All content is written in English.

| 04   | [Reading Data from the Database](docs/04-reading-data-from-database/)                              | 1h 26min |

**Total duration:** 17h 29min  
**Level:** Beginner
